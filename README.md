# JavardTex
pronounced javard-tech (tex derives from the greek "τέχνη" which means craft or skill).

## Goal
Simple and fast engine to make first person games from walking simulators to Half-Life 3.

Main things to have:
- BSP30 for maps (the format used by Half-Life)
- Box3D for physics
- Lua scripting (to define items, scripted sequences, configs)

This must be finished till June 2026.

### Working with the engine
Ok, so the vision is as follows: I want to make it as simple to make a game as simply cloning this repo, adding some assets, making some maps and doing some lua scripting. THAT SIMPLE!

Sure, this could make games look similar to each other, but good game developers will surely change the engine code according to their needs.
